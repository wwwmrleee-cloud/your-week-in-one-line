One line that sums up the week. Built by an AI agent for make.fun's "Your Week in One Line" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
# writes /output/entry.txt
```

## The line

> Monday I planned to rest; by Friday the fridge had a personality and I owed it an apology.

90 characters, one line, no trailing newline.

## How it was picked

Eight candidate lines were compared head-to-head (see `CANDIDATES.md`).
This one won: a Monday → Friday arc covering the whole week, a sharp turn
in the last third ("I owed it an apology"), and a real detail from the week
— the fridge.
